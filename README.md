# Ruben Scalante — Portfolio CV

Personal portfolio and interactive CV for Ruben Dario Scalante Rojas, Backend Developer (.NET / Cloud).

## Features

- Dark modern design
- Bilingual content (ES / EN) with one-click toggle
- Sections: About, Tech Stack, Experience, Education, Projects, Certifications
- Scroll-triggered animations
- Fully responsive (mobile-first)
- Zero dependencies — vanilla HTML, CSS, JS

## Structure

```
ruben-scalante-rojas-cv/
├── index.html              # Entry point — semantic HTML structure
├── assets/
│   ├── css/
│   │   ├── main.css        # CSS variables, reset, layout, typography
│   │   └── components.css  # Section-specific component styles
│   ├── js/
│   │   ├── i18n.js         # All ES/EN translations
│   │   └── main.js         # Language toggle, scroll animations, UI logic
│   ├── images/
│   │   ├── profile.jpg     # Profile photo
│   │   └── favicon.svg     # Site favicon
│   └── docs/
│       └── CV_Ruben_Dario_Scalante_Rojas.pdf  # Downloadable CV
├── .gitignore
└── README.md
```

## Getting Started

No build step required. Just open `index.html` in any browser.

## Deployment

Compatible with GitHub Pages, Netlify, Vercel, or any static host.
Drop the folder contents into the root of your hosting service.
